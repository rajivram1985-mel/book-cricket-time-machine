Privacy Policy — Book Cricket Time Machine

Last updated: 27 July 2026

Book Cricket Time Machine is a free, nostalgic browser game. The short version: there are no accounts, no ads, no cookies, and your scorebook never leaves your device. Only an anonymous count of which parts of the game get used is sent anywhere else, and only if you leave that setting on.

What data the app collects

The app uses Umami, a privacy-focused analytics service, to count a small number of anonymous events — things like "a Classic match started," "the Daily Challenge was shared," "a friend challenge link was created or opened," "the how-to-play panel was opened," or "a bowling plan, Review, or page-call was used" (eight event types in total). Each event carries only a coarse category (which game mode, win or loss) — never a name, email, or exact address.

To group events together, Umami computes a one-way hash from your IP address, browser/OS details, and this site's ID, and uses that hash as a temporary session identifier; it also records your approximate country (derived from your IP address, which Umami discards rather than storing), and your browser and operating system. Umami doesn't use cookies, and it rotates the hashing salt behind that session identifier on a schedule it controls and doesn't publish — we don't rely on, or claim, any specific rotation interval. What we can say plainly: no event ever carries a name, email, or persistent device identifier, and nobody — us included — can look at this data and answer "what did one specific person do." We only ever see aggregate counts, like "the Daily Challenge was started 40 times this week."

The app has no user accounts, no sign-in, and no advertising of any kind. You can turn this off entirely at any time from the "Anonymous usage stats" checkbox in the game's header — it's a real opt-out: unticking it removes the tracking script itself, not just a flag, so nothing is sent on your next visit either.

Challenge links

The “Challenge a friend” button builds a link that carries only match details — the score to beat, the players and the book — and never a name or anything about the person who made it. The link travels through whatever chat app you choose to share it in; the challenge details ride in the part of the address (after the “#”) that browsers never send to any server, including ours.

What's stored on your device

Your scorebook — matches played, win/loss record, daily-challenge streaks, personal bests and sound preferences — is saved in your browser's local storage, on your device only. It is never included in any analytics event and never transmitted anywhere. You can wipe it at any time with the “Reset data” link in the app's footer.

Backups

The “Back up” button saves your scorebook as a file to your own device's downloads. That file goes wherever you choose to put it — it is never uploaded anywhere by the app.

Network use

The app downloads its own game files (pages, images, typefaces, scripts) from our web host when you first load or update it, like any website. These requests carry no personal information beyond what any standard web request contains. After the first visit, the core game works offline. Commentary voice clips are fetched the first time each one is actually played and cached from then on — so a given clip plays offline only after you've heard it once with a connection; clips you've never triggered still need one. Separately, the anonymous usage events described above are sent to Umami's servers (only if the "Anonymous usage stats" setting is on). The app loads no other third-party resources at all — no fonts, ads, trackers, or embeds from anyone else's servers, so no visitor's IP address reaches any host besides our own and, when opted in, Umami's.

Children

The game is safe for all ages. The anonymous usage counts described above never include anything that could identify an individual player, child or adult.

Changes to this policy

If the app's data practices ever change (for example, if optional online features are added someday), this page will be updated before those changes ship, and the app's store listing will reflect it.
